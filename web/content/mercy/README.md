# Investigation: Mercy / Wombs (ر-ح-م)

> The first concept analyzed in the project. Proof-of-workflow for the root-anchored knowledge graph approach.

## Topic

A first-principles study of the root **ر-ح-م** (rḥm) — the Quran's vocabulary for divine mercy. The headline finding: this same root literally names the **womb** (`أرحام` arḥām). The Quran's defining divine attribute (*ar-Raḥmān, ar-Raḥīm*) is etymologically anchored in the maternal-protective bond, not in abstract benevolence.

## Headline findings

1. **The wombs–mercy etymology** — lemma 5 (`>aroHaAm`, "wombs/kinship") sits in the same root as the divine attribute. Mercy is named after the maternal bond.
2. **Three behavioral clusters** — mercy operates as (a) divine attribute, (b) salvation pathway with forgiveness, (c) sovereign discretionary grant.
3. **Translator divergence as signal** — Khattab uniquely substitutes "family ties" for "wombs" in 4:1; the others preserve "wombs."
